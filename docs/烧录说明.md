# ESP32-S3 桌面时钟 —— 固件烧录说明

## 〇、五分钟上手(拿到板子 + 这份固件之后)

### 先准备三样

| | 说明 |
|---|---|
| **USB-C 数据线** | 必须是**能传数据**的线。很多线只有电源线,插上电脑根本不认串口 —— 这是最常见的"卡住"原因 |
| **TF 卡**(强烈建议) | 32GB 以内、**FAT32** 格式。音乐要从卡里读,**WiFi 也靠卡来配** |
| **电脑** | Windows / macOS / Linux 都行 |

---

### 第 1 步:准备烧录工具(二选一)

**方式 A —— 用本包自带的 `烧录.bat`(最省事)**

它的本质是调用 `esptool`。装过 **ESP-IDF** 的电脑上已经有了;
没装过就装个 Python,然后:

```
pip install esptool
```

**方式 B —— 乐鑫官方的 Flash Download Tool(纯图形界面,不用装 Python)**

到乐鑫官网搜 **Flash Download Tool**,下载解压后双击 `flash_download_tool_*.exe`。
各栏怎么填见下面第三节。

> 💡 如果电脑上装了 **VS Code + ESP-IDF 插件**,也可以直接在 VS Code 里点
> "Select port to use" 选串口,再点 ⚡(Flash)按钮烧 —— 见第三节末尾。

---

### 第 2 步:确认电脑认出了串口

插上 USB-C 线,打开「**设备管理器 → 端口 (COM 和 LPT)**」,
应该多出一个 `COMx`(比如 `COM5`)。**把这个编号记下来**,下一步要用。

**认不出来?** 按顺序试:

1. **换一根确定能传数据的线** —— 九成是这个原因
2. 换一个 USB 口(别用机箱前面板,也别插 USB hub)
3. 还不行就手动进下载模式:按住 **BOOT** 键不放 → 点一下 **RST** → 再松开 BOOT

> 💡 **这块板子用不着装 USB 转串口驱动。**
> 它用的是 ESP32-S3 **芯片内置的 USB**(设备管理器里能看到
> `VID_303A`),Windows 10/11 自带驱动,插上就认。
> 所以如果你在到处找 CH340 / CP210x 驱动 —— 不用了,
> 认不出来就是**线**或**USB 口**的问题。

---

### 第 3 步:先配好 WiFi(**建议在烧录前做**)

1. 把本目录的 **`wifi.txt` 拷到 TF 卡的根目录**(不是子文件夹里)
2. 用记事本打开,把这两行前面的 `#` 去掉,填上自己的:

   ```
   ssid=你家的WiFi名字
   pass=你家的WiFi密码
   ```

3. **保存**(编码 UTF-8;Windows 11 记事本默认就是)
4. **把卡插到板子上**

> 为什么建议先做:这样烧完第一次开机就直接连上网了,省一次重启。
> 顺序反了也没关系,插好卡再断电重上一次就行。
>
> 📖 完整说明(格式规则、排错、静态 IP)见 **`WiFi配置说明.md`** /
> **`How_to_Configure_WiFi.md`**。

---

### 第 4 步:烧录

双击 **`烧录.bat`**。(它默认用 `COM3`,和你第 2 步记下的多半不一样)

串口不对就把串口当参数传进去:

```
烧录.bat COM5
```

看到这一行就成功了:

```
==============  烧录完成!  ==============
```

板子会自动重启。

> **烧进去的是什么**:一个合并好的**单文件镜像**,直接写到地址 **`0x0`**,
> 里面已经包含了 bootloader + 分区表 + 应用程序。
> ⚠️ 它会**把整片 flash 擦掉** —— 板子上原来的固件和 WiFi 记录都没了。

---

### 第 5 步:看屏幕 + 跑上位机

1. 屏幕**左上角**应该显示**你的 WiFi 名字**;过几秒时间会通过 NTP 校准
2. **记下左上角那串 `IP:端口`** —— 下一步要用
3. 电脑上双击 **`电脑资源监视器\电脑资源监视器.exe`**

   它自己会扫局域网找板子。找不到就手动传 IP(**就是第 2 步记下那个**):

   ```
   电脑资源监视器.exe 192.168.1.123
   ```

看到 `已连接` 就成了 —— 板子时钟页左下角的柱子、以及曲线页,会开始动。

---

### 一句话总结

```
插线 → 认串口 → 卡上放 wifi.txt → 双击 烧录.bat → 双击 电脑资源监视器.exe
```

下面几节是可以查阅的细节:板子规格、烧录参数、配网详解、按键、常见问题。

## 一、这块板子是什么

Waveshare **ESP32-S3-RLCD-4.2**:400×300 单色**反射式**液晶(没有背光、没有触摸),
主控 ESP32-S3-WROOM-1-N16R8(16MB flash + 8MB PSRAM)。

功能:联网时钟(时间/日期/温湿度/电池/充电状态)、音乐播放(读 TF 卡里的 WAV)、
音乐频谱(音乐 / 麦克风 / 电脑推流 三种源)、电脑资源监控(顶栏 5 根资源柱
+ 一整页四张历史曲线)。

> 本包里的固件是 **2026-09-30 修订版**,相比早先那版多了:
> 时钟换成了白底+网格的方块点阵字形、顶部状态栏图标化、资源柱增加到 5 根、
> 历史曲线加了 Y 轴横向网格线、频谱改用 4096 点 FFT(低频分得开了)。

## 二、烧之前必须知道的事

| 项目 | 要求 |
|---|---|

| **TF 卡** | **建议插一张**。音乐要从卡里读 WAV;**WiFi 也要靠卡来配**(见第四节) |

> 想留后路就先把原厂固件备份出来。

## 三、烧录(两种方式,任选一种)

固件是**单个文件**,直接写到地址 **0x0** 就行 ——
bootloader、分区表、应用程序都已经合并进去了。

### 方式 1:命令行(电脑上有 esptool 的话最省事)

双击 **`烧录.bat`**(默认串口 `COM3`)。

串口不对的话,把串口当参数传进去:

```
烧录.bat COM5
```

### 方式 2:乐鑫官方 Flash Download Tool(纯图形界面)

1. 到乐鑫官网下载 **Flash Download Tool**,解压后双击 `flash_download_tool_*.exe`
2. 芯片选 **ESP32-S3**,工作模式选 **Develop**
3. 按下表填:

   | 项目 | 填什么 |
   |---|---|
   | 第 1 行 文件 | `firmware_friend_20260930.bin` |
   | 地址 | **`0`** ←注意是 0,不是 0x10000 |
   | SPI SPEED | **80MHz** |
   | SPI MODE | **DIO** |
   | Flash SIZE | **16MB** |
   | COM | 你的串口(设备管理器 → 端口) |
   | BAUD | 921600(不稳就降成 460800 / 115200) |

4. 点 **START**,等进度条走完,板子会自动重启

### 方式 3:VS Code + ESP-IDF 插件(已装开发环境的用这个)

前提是电脑上装了 **VS Code** 和 **Espressif IDF** 插件。

1. 打开任意一个 ESP-IDF 工程文件夹(空的也行)
2. 底部状态栏点 **⚡ 图标 → Select port to use** → 选你的 COM 口
3. 按 `Ctrl+Shift+P`,运行 **`ESP-IDF: Flash (UART) your project`**

> 注意:这条命令烧的是**当前工程编译出来的**东西。想烧本包的
> `firmware_friend_20260930.bin`,用方式 1 或方式 2。
> (或者把 bin 放到工程根目录、在 VS Code 里跑
> `esptool.py --chip esp32s3 write_flash 0x0 firmware_friend_20260930.bin`)

## 四、配网(WiFi)★ 重点

这个固件的 WiFi **不是**用手机 App 配的,而是**开机时读 TF 卡根目录的 `wifi.txt`**。

> 📖 **完整说明(含排错、静态 IP、中英双语)在另外两个文件里:**
> - **`WiFi配置说明.md`**(中文)
> - **`How_to_Configure_WiFi.md`**(English)
>
> 下面是精简版。

### 步骤

1. 把同目录的 **`wifi.txt`** 拷到 **TF 卡的根目录**
2. 用记事本打开它,把下面两行前面的 `#` 去掉,填上你自己的 WiFi:

   ```
   ssid=你家的WiFi名字
   pass=你家的WiFi密码
   ```

3. **保存**(编码用 UTF-8;Windows 11 的记事本默认就是,不用动)
4. 卡插回板子,**重新上电**

连上了,屏幕左上角会显示你的 WiFi 名字;没配上会显示 `no wifi`。

### 没有 TF 卡会怎样?

板子照常开机能用:时间用板载 RTC 芯片里存的旧时间,
音乐、频谱、温湿度、电池都正常。
只有 **联网对时** 和 **电脑资源监控** 用不了。

### 写法很宽松,不用刻意讲究

- `ssid=` / `SSID=` 大小写都认;`pass=` 和 `password=` 都认
- 等号两边有空格也认(`ssid = 我的网`)
- Windows 换行(CRLF)、记事本默认加的 UTF-8 BOM 都能正确处理
- 中文 WiFi 名字直接写
- `#` 开头的整行是注释

## 五、第一次开机应该看到什么

用 115200 波特率看串口日志,应该类似这样:

```
I (1552) clock: 正在连接 WiFi "你家的WiFi" ...
I (1622) wifi:connected with 你家的WiFi ...
I (3217) clock: WiFi 已连接,IP = 192.168.x.x
I (3219) clock: SNTP 已启动  服务器:ntp.aliyun.com
I (3980) clock: NTP 对时成功: 2026-09-30 01:58:11
I (4029) clock: 时间已写入 PCF85063 RTC
```

这一版开机时还会多打几行自检,方便确认状态(不是出错):

```
I (1064) spectrum: 频谱就绪: 4096 点 FFT / 90 频段 / 94~20000Hz @48000Hz
I (1145) spectrum: FFT 自检: 4096 点 x10 次 = 71ms,平均 7.10 ms/次
I (1898) clock: 任务全部启动完毕,内部 RAM 剩余 18295 字节(堆总剩余 8009531)
```

> 给朋友那版走 **DHCP**,IP 由路由器分,所以上面那行是 `192.168.x.x` ——
> 具体多少看**板子屏幕左上角**(格式 `IP:端口`)。

如果配网没成功,日志会明确告诉你卡在哪一步:

| 日志 | 意思 |
|---|---|
| `TF 卡里没有 /sdcard/wifi.txt` | 卡里没这个文件(或不在根目录) |
| `/sdcard/wifi.txt 里没找到可用的 ssid=` | 文件在,但 ssid 那行被注释掉了或写空了 |
| `已从 TF 卡读到 WiFi 配置: "xxx"` | 读到了,接下来看能不能连上 |
| `没配过 WiFi:把 wifi.txt 放进 TF 卡根目录后重启` | 完全没有可用凭据 |

## 六、按键

板子上只有两个可用按键(这块屏没有触摸):

| 按键 | 操作 | 时钟页 | 音乐页 | 曲线页 |
|---|---|---|---|---|
| **KEY**(GPIO18) | 短按 | 切页 → | 切页 →(等 0.3 秒看是不是双击) | 切页 → |
| | 长按 | 12/24 小时制 | 下一首 | 立即重画一次 |
| | 双击 | — | 上一首 | — |
| **BOOT**(GPIO0) | 短按 | — | 播放 / 暂停 | — |
| | 长按 | — | **按住不放就在 3 个频谱源之间轮换**(每 2 秒换一个),松手就定在当时的那个 | — |

**三个频谱源**:播放音乐(TF 卡) → 麦克风 → 电脑推流,循环。
选中的是哪个,看音乐页右上角的字(`播放中` / `麦克风频谱` / `电脑推流`)
和中间那行(`来自本地` / `麦克风` / `来自电脑`)。

**还有一个例外**:

- 电脑正在推流时,**长按 KEY = 停止推流**(任意页面都生效)。
  推流时 TF 卡已经让出了播放通道,“下一首”本来就无意义,正好空着;
  而停止推流是个不可逆的动作,不该跟“轮换频谱源”抢同一个键。
- 电脑正在推流时,**短按 BOOT = 推流暂停 / 继续**。

## 七、常见问题

**Q:屏幕不亮 / 一片白**
A:这块屏是**反射式**的,**没有背光** —— 靠环境光显示。拿到亮的地方看。
在暗处本来就什么都看不到,这不是坏了。

**Q:烧录报 "Failed to connect"**
A:1) 串口编号对不对;2) 关掉所有占串口的软件(串口监视器 / Arduino IDE);
3) 换一根能传数据的线;4) 不行就按住 BOOT 键,点一下 RST 再松开 BOOT,进下载模式重试。

**Q:烧完之后板子一直重启,串口反复报 `Factory app partition is not bootable`**
A:这是**烧录中途断了** —— 固件只写进去一半。常见原因是拔了线、
或者用了会“提前结束命令”的方式去跑烧录工具(比如把输出管道给一个
只取前几行的过滤器)。

**修复:什么都不用改,完整重新烧一次就好**(换根好线、别中途打断)。
板子本身没坏 —— 只是 flash 里现在是个写坏的 app 分区。

**Q:连不上 WiFi**
A:按顺序查:1) `wifi.txt` 是在**卡根目录**吗(不是子目录);
2) 文件名是不是正好 `wifi.txt`;3) 保存成 UTF-8 了吗;
4) 看串口日志里 `clock:` 那几行,它会明确说是"没找到文件"还是"读到了但连不上"。
另外注意:这块板子只支持 **2.4GHz** WiFi,**连不上 5GHz**。

**Q:音乐不播**
A:TF 卡根目录要有 `.wav` 文件(WAV,16bit PCM,44.1kHz 或 48kHz 都行)。

**Q:时间不对**
A:没连上网时用的是 RTC 里的旧时间。连上 WiFi 后会自动 NTP 对时,然后写回 RTC,
以后断电也不会丢(板子上有纽扣电池位的)。

## 九、两个固件到底差在哪

| | `firmware_friend_...`(给朋友) | `firmware_self_...`(自己用) |
|---|---|---|
| WiFi 凭据 | **不编进去**,靠 TF 卡 `wifi.txt` | 写死了 `MIKU` |
| IP 地址 | **DHCP**(路由器分) | **静态 `192.168.1.182`** |

静态 IP 是为了让电脑上的推流/监视程序固定连一个地址,不用来回改配置 ——
但那段网段是按作者家里路由器填的,**换到别的网络上会连不上网关**
(现象:WiFi 名字显示了,但时间永远同步不了)。所以给朋友的那版已经关掉了。

> ⚠️ **千万别把 `自己用-别给朋友\` 里的东西发出去** —— 那个 bin 里能用
> 十六进制编辑器直接搜到 WiFi 密码。
