# 电脑资源监视器(上位机)

把电脑的 CPU / 内存 / GPU / 网速实时推给板子,显示在板子的**时钟页资源柱**
和**曲线页历史图**上。

---

## 一、怎么用

**双击 `电脑资源监视器.exe` 就行。**

正常的话窗口里会出现类似这样的输出:

```
GPU  : NVIDIA GeForce GTX 1060 6GB  (nvidia-smi 子进程,较慢)
主机 : ZXS
目标 : 192.168.1.182:3334   采样 1.0s
已连接 192.168.1.182:3334
HOST=ZXS CPU=11.5 RAM=71.9 RAMU=23432 RAMT=32609 CPUT=-1 GPU=11 GPUT=54 ...
```

看到 `已连接` 就是通了。**按 Ctrl+C 停止。**

板子那边:时钟页左下角那几根柱子里,CPU / GPU / 内存 / ↓ / ↑ 就会动起来。

## 二、常见问题

**Q:提示「没找到板子,请手动指定 IP」**

板子和电脑不在同一个网段,或者板子还没开机。手动传 IP:

```powershell
电脑资源监视器.exe 192.168.1.182
```

> 作者自己用的固件把板子 IP 写死在 **192.168.1.182**(见 WiFi 配置说明第四节)。
> 如果你的板子走 DHCP,地址在**板子屏幕左上角**能看到(格式 `IP:端口`)。

**Q:CPU 温度显示 `--`**

Windows **不开放** CPU 温度给普通程序,必须借第三方工具。程序会自动尝试:

1. **LibreHardwareMonitor**(免费开源,推荐)—— 跑起来就行,它会开一个 WMI 接口
2. **HWiNFO** —— 需要在设置里打开「写入注册表」

两个都没有,这一项就发 `-1`,板子上显示 `--`。其余数据不受影响。

**Q:GPU 那一栏是 `--`**

没装 NVML(nvidia-ml-py)时会退回调用 `nvidia-smi` 子进程,所以电脑上要能跑
`nvidia-smi`。想更快、更省 CPU 就装一下:

```powershell
pip install nvidia-ml-py
```

**Q:杀毒软件报毒**

PyInstaller 打出来的单文件 EXE 有自解压行为,容易被各家杀软误报。
不放心的话可以直接跑源码(需要 Python 和 `pip install psutil`):

```powershell
python pc_monitor.py
```

同目录已经附上源码 `pc_monitor.py` 和完整注释。

## 三、命令行参数

| 参数 | 说明 |
|---|---|
| `host` | 板子 IP。不填则自动扫描局域网找板子 |
| `--port 3334` | 端口,不用改 |
| `--rate 1.0` | 每秒推几次 |
| `--interval 1.0` | 采样周期(秒) |
| `--echo` | 每条数据也打到屏幕上 |
| `--dry-run` | 只采样打印,不连板子(验证数据源用) |
| `--count N` | 采 N 条就退出,0 = 一直跑 |

例子:

```powershell
电脑资源监视器.exe --dry-run --count 3      # 先看看能不能取到数据
电脑资源监视器.exe 192.168.1.182 --echo     # 指定 IP,并把数据打出来
```

## 四、数据格式(想自己写一个的话)

TCP 连到板子的 **3334** 端口,每行一条,`键=值`,空格分隔:

```
HOST=ZXS CPU=12 RAM=34 RAMU=16941 RAMT=32609 CPUT=27 GPU=3 GPUT=52 VRAMU=1627 VRAMT=6144 NETRX=12 NETTX=3
```

| 键 | 含义 |
|---|---|
| `HOST` | 电脑名 |
| `CPU` | CPU 占用 % |
| `RAM` | 内存占用 % |
| `RAMU` / `RAMT` | 已用 / 总内存(MB) |
| `CPUT` | CPU 温度 ℃,取不到发 `-1` |
| `GPU` | GPU 占用 % |
| `GPUT` | GPU 温度 ℃ |
| `VRAMU` / `VRAMT` | 显存已用 / 总量(MB) |
| `NETRX` / `NETTX` | 下行 / 上行(KB/s) |

不需要任何握手,连上就开始发。
