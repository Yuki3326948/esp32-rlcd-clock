# WiFi 配置说明

这块板子的 WiFi **不是**用手机 App 配的。有两条路,优先用第一条。

---

## 一、推荐:TF 卡根目录放一个 `wifi.txt`

**不用重新编译、不用重新烧录**,改完重启就生效 —— 换 WiFi 就该用这个办法。

### 步骤

1. 把 `wifi.txt` 拷到 **TF 卡的根目录**(不是子文件夹里)
2. 用记事本打开,把这两行前面的 `#` 去掉,填上自己的:

   ```
   ssid=你家的WiFi名字
   pass=你家的WiFi密码
   ```

   完整的文件长这样(注释行留着不影响):

   ```
   # 我家的网
   ssid=MyHomeWiFi
   pass=Abc12345678
   ```

3. **保存**。编码用 UTF-8 —— Windows 11 的记事本默认就是,不用动。
4. 卡插回板子,**重新上电**。

连上后,屏幕**左上角会显示你的 WiFi 名字**。没配上会显示 `no wifi`。

### 格式规则(写得很宽松,不用刻意讲究)

| 情况 | 认不认 |
|---|---|
| `ssid=` / `SSID=` / `Ssid=` | ✅ 大小写都认 |
| `pass=` / `password=` | ✅ 都认 |
| `ssid = 我的网`(等号两边有空格) | ✅ |
| 中文 WiFi 名字 | ✅ 直接写,不用转义 |
| Windows 换行(CRLF) | ✅ |
| 记事本默认加的 UTF-8 BOM | ✅ |
| `#` 开头的整行 | 当注释跳过 |
| 单行超长 | 自动截断到 32 字节(802.11 的硬限制) |

### 怎么确认读进去了

用 115200 波特率看串口日志,找 `clock:` 开头那几行:

| 日志 | 意思 |
|---|---|
| `已从 TF 卡读到 WiFi 配置: "xxx"` | ✅ 读到了,接下来看能不能连上 |
| `TF 卡里没有 /sdcard/wifi.txt,继续用默认凭据 "xxx"` | 卡里没这个文件,或不在根目录 |
| `/sdcard/wifi.txt 里没找到可用的 ssid=,忽略` | 文件在,但 ssid 那行被注释掉或写空了 |
| `没配过 WiFi:把 wifi.txt 放进 TF 卡根目录后重启` | 完全没有可用凭据(固件里也没编) |

## 二、另一种:直接编进固件

只适合**自己用**的固件(给别人用的固件默认不带凭据)。

源码 `components/user_app/user_app.cpp` 里找这两个宏:

```c
#define WIFI_SSID        "MIKU"
#define WIFI_PASSWORD    "GBN1213326948"
```

改成自己的,然后重新编译烧录:

```powershell
& L:\ESP32\tools\build.ps1 -p COM5 build flash
```

> ⚠️ **编进固件的密码是明文躺在 bin 文件里的**,任何人都能搜出来。
> 要发给别人就必须编"凭据留空"版:
> ```powershell
> & L:\ESP32\tools\build.ps1 -DWIFI_CREDENTIALS_EMPTY=ON build
> ```
> 发之前用十六进制编辑器搜一下自己的密码,确认搜不到再发。

## 三、两条路同时存在时,谁生效?

**TF 卡的 `wifi.txt` 优先。**

启动流程是这样的:

1. 先用**固件里编的**凭据去连(所以自己用的时候,开机 1.6 秒就连上了);
2. TF 卡挂载完之后,后台任务再读一次 `wifi.txt`;
3. 读到了就**覆盖并重连**。

所以有两种情况要注意:

- ✅ 想换 WiFi 又不想重刷固件 → 改 `wifi.txt` 就行,连固件里编的也会被它盖掉。
- ⚠️ **卡里的 `wifi.txt` 写错了会连累固件里的正确凭据** —— 因为它会覆盖。
  如果本来连得好好的,插了张带 `wifi.txt` 的卡反而连不上,先查那张卡。

## 四、静态 IP(只影响"自己用"那版)

自己用的固件可以给板子指定一个**固定地址**,这样电脑上的推流/监视程序
不用每次去找板子。

**不带静态 IP 时走 DHCP**(路由器分地址),这也是默认行为。
地址多少看**板子屏幕左上角**(格式 `IP:端口`)。

两种模式在开机日志里能直接区分:

```
I (1527) clock: 静态 IP: 192.168.1.182  网关: 192.168.1.1
```
或者
```
I (xxxx) clock: 网络: DHCP(没定义静态 IP)
```

### 想启用固定地址要怎么改

静态 IP 是**按具体网络填的**,而每个人的网段不一样,所以它没写在源码里,
而是放在那个**不进版本库**的 `wifi_secrets.h` 里。

打开 `components/user_app/wifi_secrets.h`,把这 6 行改成自己的:

```c
#define STATIC_IP_0      192
#define STATIC_IP_1      168
#define STATIC_IP_2      1
#define STATIC_IP_3      182
#define STATIC_GW_0      192      // 网关
#define STATIC_GW_1      168
#define STATIC_GW_2      1
#define STATIC_GW_3      1
```

然后重新编译烧录。

> ⚠️ **换到别的网络时要把它注释掉**。写死的 `192.168.1.x` 放到别人网段上,
> 会出现「WiFi 名字显示出来了,但时间永远对不上」—— 因为拿不到网关,
> 域名解析不了。而且可能正好撞上人家网里已有的设备。
>
> 地址也别落在路由器的 DHCP 池里,否则可能和别的设备撞车
> (路由器分地址时不会考虑已经在用的人)。

## 五、排错

**Q:屏幕一直显示 `no wifi`**

按这个顺序查:

1. `wifi.txt` 是在 **TF 卡根目录**吗(不是某个子文件夹里)?
2. 文件名是不是正好是 `wifi.txt`?(`wifi.txt.txt` 是 Windows 最常见的坑 ——
   资源管理器默认藏扩展名,改完名字看着对其实多了个 `.txt`)
3. 里面那两行前面的 `#` 去掉了没有?
4. 看串口日志里 `clock:` 那几行,它会明确告诉你是"没找到文件"还是
   "读到了但连不上"。

**Q:WiFi 名字能显示,但时间不对**

大概率是静态 IP 的事 —— 见上面第四节。看日志里有没有那一行「静态 IP:」。

**Q:连不上,一直重试**

- 这块板子只支持 **2.4GHz**,**连不上 5GHz**。路由器如果双频合一
  用了同一个名字,可以试着在路由器里把 2.4G 的名字单独改一个。
- WiFi 名字区分大小写,前后别多空格。
- 密码里的字符直接写,不需要引号。

**Q:插了别的卡之后连不上了**

那张卡根目录里可能有 `wifi.txt`,内容覆盖了原来的正确凭据(见第三节)。
拔掉卡或者改对卡里的内容。
