# ──────────────────────────────────────────────────────────
#  WiFi 配置
#
#  怎么用:
#    1) 把本文件放到 TF 卡的【根目录】,文件名必须正好是 wifi.txt
#    2) 把下面两行前面的 " # " 去掉,填上你自己的 WiFi 名字和密码
#    3) 保存(编码选 UTF-8;Windows 11 的记事本默认就是,不用改)
#    4) 卡插回板子,重新上电
#
#  注意:
#    - 以 # 开头的行是注释,程序会跳过
#    - WiFi 名字区分大小写,注意别多打空格
#    - 名字里带中文也可以,直接写,不用转义
#    - 大小写、等号两边的空格、Windows 换行、记事本加的 BOM
#      程序都能容错,不用刻意避开
# ──────────────────────────────────────────────────────────
